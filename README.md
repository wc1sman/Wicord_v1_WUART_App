Electron Installation Instructions:
1.Check that Node.js and npm are installed correctly

	//To check that Node.js was installed correctly, type the following commands in your terminal client:

	node -v
	npm -v

2.Open Project Folder in Visual Studio Code

3.In Visual Studio Terminal type :
	npm install --save-dev electron -> Mac Os
	npm install --platform=win32 electron -> Windows


App Is Ready 

4. To launch App type:
	npm start



Packaging

npm run dist


Developer Tools -> Enable Goto main.js 
devTools: false -> change to true
